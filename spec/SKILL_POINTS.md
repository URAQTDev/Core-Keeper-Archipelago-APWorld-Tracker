# Skill Points option

`Skillsanity` controls only level-threshold location checks.

`Skill Points` is an independent reward toggle. When enabled, Core Keeper's
normal level-earned talent points are suppressed and the item pool receives
five `+5 Skill Points` rewards for each of the twelve skills. When disabled,
normal Core Keeper talent-point behavior remains unchanged and those rewards
are absent.

The Skill XP Multiplier is independent of both toggles.
