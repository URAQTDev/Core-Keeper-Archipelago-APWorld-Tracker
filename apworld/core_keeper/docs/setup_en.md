# Core Keeper Multiworld Setup

This package is the evidence-validated Core Keeper Archipelago 0.9.0-rc.8 release candidate.

1. Install `core_keeper.apworld` with **Install APWorld** in the Archipelago
   Launcher, then restart Archipelago if prompted.
2. Create a Core Keeper YAML with the same slot name the player will enter in
   game, then generate and host a new room. Reusing a room generated by an
   older APWorld will not add newer locations.
3. Extract the matching `CoreKeeperArchipelago` folder into
   `Core Keeper/CoreKeeper_Data/StreamingAssets/Mods`, then restart the game.
4. From Core Keeper's main menu, open **Settings**, select **Archipelago**, and
   enter `ws://host:port` (or `wss://host:port` for a secure host), the exact
   slot name, and the optional password. Select **Save and Connect**.
5. Wait for `Saved. Connected.` before testing checks.

All APWorld, mod, and tracker files must come from the same build. The current
client observes the player's complete authoritative item buffer, including the
four pouch inventory ranges defined by the game.

The Core Keeper mod, APWorld, and tracker must be updated together. A room
generated with a different Core Keeper APWorld version is not supported.
