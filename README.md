# Core Keeper Archipelago APWorld and Tracker

Archipelago world generation, logic, PopTracker support, and the optional local
texture helper for Core Keeper Archipelago.

> **Community testing release:** Core Keeper is currently distributed as a
> custom Archipelago world. It is not included in official Archipelago builds.

## Download and install

Download the files from the
[latest release](https://github.com/URAQTDev/Core-Keeper-Archipelago-APWorld-Tracker/releases/latest):

1. Install `core_keeper.apworld` using **Install APWorld** in the Archipelago
   Launcher. This is also required before creating a Core Keeper options YAML.
2. Subscribe to **Core Keeper Archipelago** through Core Keeper's in-game
   **Mods** menu.
3. Optionally install `core_keeper_poptracker_texture_free_1.0.1.zip` in
   PopTracker, or run `CoreKeeperArchipelago-Tracker-Setup-1.0.1.zip` to create
   the locally textured tracker from your installed Core Keeper files.

The APWorld, mod, and tracker must use the same release version.

The tracker remains usable without Core Keeper artwork. The texture helper
creates a textured copy from the player's own installed Core Keeper files; this
repository does not redistribute extracted game artwork.

The matching in-game client mod is maintained at
[Core-Keeper-Archipelago](https://github.com/URAQTDev/Core-Keeper-Archipelago)
and is installed through Core Keeper's in-game **Mods** menu.

Current public-testing release: `1.0.1`
