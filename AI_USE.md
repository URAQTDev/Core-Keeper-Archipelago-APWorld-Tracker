# AI Use Disclosure

This project was developed with substantial assistance from generative AI,
primarily OpenAI ChatGPT and Codex. AI assistance was used for code generation,
logic implementation, test creation, tracker construction, documentation,
asset-extraction tooling, debugging, and release packaging.

Project direction, randomizer design, placement and logic decisions, acceptance
criteria, gameplay testing, visual review, and release approval were provided
by the human maintainer, URAQTDev. AI-produced changes were reviewed and tested
against the supported Core Keeper, Archipelago, and PopTracker versions before
release.

The local texture helper reads artwork from the player's installed Core Keeper
files. Generative AI is not used to create replacements for extracted game
artwork.

Bug reports and logic concerns should be submitted through this repository's
Issues page and will be evaluated by the maintainer.
